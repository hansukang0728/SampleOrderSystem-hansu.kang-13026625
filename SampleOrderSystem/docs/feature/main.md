# 메인 메뉴 (Main Menu)

> 참조: [PRD.md](../../PRD.md)

---

## 1. 개요

SampleOrderSystem 진입 시 표시되는 최상위 메뉴.  
모든 기능 진입점이며, 번호 입력으로 기능을 선택한다.

---

## 2. 메뉴 구성

```
============================================================
      SampleOrderSystem  ·  시료 주문 관리 시스템
============================================================
  1. 시료 관리          (등록 / 조회 / 검색)
  2. 시료 주문          (주문 생성)
  3. 주문 승인 / 거절   (RESERVED 주문 처리)
  4. 모니터링           (재고 현황 / 주문 현황)
  5. 생산 라인 조회     (생산 큐 확인 / 처리)
  6. 출고 처리          (CONFIRMED 주문 출고)
  7. 더미 데이터 / 초기화
  0. 종료
------------------------------------------------------------
선택:
```

---

## 3. 메뉴 항목 정의

| 번호 | 메뉴명 | 이동 대상 | 관련 문서 |
|---|---|---|---|
| 1 | 시료 관리 | 시료 관리 서브메뉴 | `sampleManage.md` |
| 2 | 시료 주문 | 주문 생성 흐름 | `sampleOrder.md` |
| 3 | 주문 승인 / 거절 | 주문 관리 서브메뉴 | `OrderManager.md` |
| 4 | 모니터링 | 모니터링 대시보드 | `Monitoring.md` |
| 5 | 생산 라인 조회 | 생산 큐 뷰 | `ProductionLine.md` |
| 6 | 출고 처리 | 출고 처리 흐름 | `Release.md` |
| 7 | 더미 데이터 / 초기화 | 더미 데이터 생성·초기화 | `dummyData.md` |
| 0 | 종료 | 프로그램 종료 | — |

---

## 4. 동작 규칙

- 잘못된 번호 입력 시 `"잘못된 선택입니다."` 출력 후 메뉴 재표시
- 각 서브메뉴에서 `0` 또는 `뒤로` 선택 시 메인 메뉴로 복귀
- 메뉴 진입 전 데이터 파일(`data.json`) 자동 로드
- 종료(0) 시 변경 사항이 이미 저장되어 있으므로 별도 저장 없이 종료

---

## 5. UI 표시 규칙

- 상단 헤더: 시스템명 표시 (항상 고정)
- 하단 구분선: `─` 58자
- 색상 (ANSI 지원 터미널):
  - 헤더: Bright Cyan + Bold
  - 선택 프롬프트: White
  - 오류 메시지: Bright Red
