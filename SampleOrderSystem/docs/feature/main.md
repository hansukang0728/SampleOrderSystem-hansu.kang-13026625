## 1. 개요

SampleOrderSystem 진입 시 표시되는 최상위 메뉴.  
모든 기능 진입점이며, 번호 입력으로 기능을 선택한다.

## 3-1. 시스템 현황 전광판

메뉴 헤더 아래에 실시간 시스템 현황을 전광판 형식으로 표시한다.  
메인 메뉴를 표시할 때마다 AppDB에서 최신 값을 읽어 갱신한다.

| 항목 | 표시 내용 | 데이터 출처 |
|---|---|---|
| 📅 현재 날짜/시간 | `YYYY-MM-DD HH:MM:SS` | `nowStr()` |
| 🧪 등록 시료 | 전체 시료 수 | `db.samples().size()` |
| 📦 총 재고 | 전체 시료 stock 합계 (ea) | `sum(sample.stock)` |
| 📋 주문 건수 | REJECTED 제외 활성 주문 수 | `activeOrders().size()` |
| 🏭 생산라인 | 큐 상태 표시 | 아래 표 참고 |

**생산라인 상태 표시 규칙**

| 조건 | 표시 | 색상 |
|---|---|---|
| 완료되지 않은 큐 없음 | `유휴 (IDLE)` | Gray |
| WAITING 항목만 존재 | `대기 (N건)` | Yellow |
| IN_PROGRESS 항목 존재 | `생산중 (진행률%)` | Green |

> WAITING과 IN_PROGRESS가 혼재하면 IN_PROGRESS 우선 표시, 대기 건수 병기: `생산중 (38%) | 대기 2건`

## 4. 동작 규칙

- 잘못된 번호 입력 시 `"잘못된 선택입니다."` 출력 후 메뉴 재표시
- 각 서브메뉴에서 `0` 또는 `뒤로` 선택 시 메인 메뉴로 복귀
- 메뉴 진입 전 데이터 파일(`data.json`) 자동 로드
- 종료(0) 시 변경 사항이 이미 저장되어 있으므로 별도 저장 없이 종료

## 5. UI 표시 규칙

- 상단 헤더: 시스템명 표시 (항상 고정)
- 하단 구분선: `─` 58자
- 색상 (ANSI 지원 터미널):
  - 헤더: Bright Cyan + Bold
  - 선택 프롬프트: White
  - 오류 메시지: Bright Red
