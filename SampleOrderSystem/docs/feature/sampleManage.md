# 시료 관리 (Sample Management)

> 참조: [PRD.md](../../PRD.md) — S-01 ~ S-05

---

## 1. 개요

시료는 시스템의 가장 기본이 되는 단위.  
시스템에 등록된 시료만 주문 가능하며, 각 시료는 고유한 ID와 속성을 가진다.

---

## 2. 서브메뉴 구성

```
============================================================
      시료 관리
============================================================
  1. 시료 등록
  2. 시료 조회 (전체)
  3. 시료 조회 (ID)
  4. 시료 검색 (이름)
  0. 뒤로
------------------------------------------------------------
선택:
```

---

## 3. 기능 상세

### 3.1 시료 등록 (S-01)

**입력값**

| 항목 | 타입 | 제약 |
|---|---|---|
| 이름 | string | 필수, 공백 불가 |
| 평균 생산시간 | double | > 0, 단위: 분/개 |
| 수율 | double | 0.0 초과 ~ 1.0 이하 |
| 초기 재고 | int | >= 0, 단위: ea |

**처리 흐름**

```
입력 받기
  → 유효성 검증
  → ID 자동 생성 (S-NNN, 순번)
  → data.json 저장
  → "등록 완료: [S-001] 시료명" 출력
```

**출력 예시**
```
이름: 알파-시료
평균 생산시간 (분/개): 30.5
수율 (0.0~1.0): 0.95
초기 재고 (ea): 100

✔ 등록 완료 — ID: S-001 | 알파-시료
```

---

### 3.2 시료 조회 — 전체 (S-02)

등록된 모든 시료를 테이블 형식으로 출력. 재고 상태 포함.

**출력 예시**
```
──────────────────────────────────────────────────────────
  ID      이름              생산시간(분)  수율(%)  재고(ea)  상태
──────────────────────────────────────────────────────────
  S-001   알파-시료               30.5    95.0       100   여유
  S-002   베타-시료               45.0    88.0         5   부족
  S-003   감마-시료               60.0    90.0         0   고갈
──────────────────────────────────────────────────────────
총 3개
```

**재고 상태 기준**

| 상태 | 조건 | 색상 |
|---|---|---|
| 여유 | stock >= 11 | Green |
| 부족 | 1 <= stock <= 10 | Yellow |
| 고갈 | stock == 0 | Red |

---

### 3.3 시료 조회 — ID (S-03)

**입력값**: 시료 ID (`S-NNN`)

**출력 예시**
```
시료 ID: S-001
──────────────────────────────────────────────────────────
  ID              : S-001
  이름            : 알파-시료
  평균 생산시간   : 30.5 분/개
  수율            : 95.0 %
  재고            : 100 ea   [여유]
──────────────────────────────────────────────────────────
```

존재하지 않는 ID 입력 시: `"존재하지 않는 시료 ID입니다."` 출력

---

### 3.4 시료 검색 — 이름 (S-04)

키워드를 포함하는 시료 목록 출력.

**입력값**: 검색 키워드 (부분 일치)

**출력 예시**
```
검색어: 알파
──────────────────────────────────────────────────────────
  S-001   알파-시료   30.5분   95.0%   재고: 100ea   여유
──────────────────────────────────────────────────────────
1건 검색됨
```

결과 없을 경우: `"검색 결과가 없습니다."` 출력

---

## 4. 유효성 검증 규칙

| 항목 | 검증 조건 | 오류 메시지 |
|---|---|---|
| 이름 | 비어있지 않아야 함 | `"이름을 입력해주세요."` |
| 평균 생산시간 | > 0 | `"생산시간은 0보다 커야 합니다."` |
| 수율 | 0.0 < yield <= 1.0 | `"수율은 0.0 초과 1.0 이하여야 합니다."` |
| 초기 재고 | >= 0 | `"재고는 0 이상이어야 합니다."` |

---

## 5. 데이터 저장

- 등록 즉시 `data.json`에 write-through 저장
- ID는 기존 최댓값 + 1로 자동 부여 (`S-NNN` 형식, 3자리 zero-padding)
