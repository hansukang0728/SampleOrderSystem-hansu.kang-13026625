# 모니터링 (Monitoring)

> 참조: [PRD.md](../../PRD.md) — M-01, M-02, M-03

---

## 1. 개요

시스템 전반의 운영 현황을 한눈에 파악할 수 있는 대시보드.  
주문 현황(상태별 건수), 재고 현황(시료별 상태), 생산 큐 현황(진행률 포함)을 함께 표시한다.  
REJECTED 상태는 모니터링 목록에서 제외하며, **조회 시마다 IN_PROGRESS 생산 항목의 경과 시간을 확인하여 완료 조건 충족 시 자동으로 재고·주문 상태를 갱신**한다.

## 3. 섹션별 상세

### 3.1 주문 현황 (M-02)

- RESERVED / PRODUCING / CONFIRMED / RELEASE 상태별 건수 출력
- **REJECTED 제외**
- 상태가 0건이어도 행 표시 (0으로 표시)

### 3.2 재고 현황 (M-01)

재고 상태 기준:

| 상태 | 조건 | 아이콘 | 색상 |
|---|---|---|---|
| 여유 | stock >= 11 | ● | Green |
| 부족 | 1 <= stock <= 10 | ▲ | Yellow |
| 고갈 | stock == 0 | ✕ | Red |

- **여유**: 현재 재고가 충분하여 즉시 출고 가능
- **부족**: 재고가 적어 추가 주문 시 생산 필요 가능성 있음 (PRODUCING 고려)
- **고갈**: 재고 수량이 0, 승인 즉시 생산 큐에 등록됨

### 3.3 생산 큐 현황 (M-03)

- 완료되지 않은(`completed == false`) 생산 큐 항목 목록
- FIFO 순서(enqueued_at 오름차순)로 표시
- 항목 없을 경우: `"진행 중인 생산 작업이 없습니다."` 출력

**출력 컬럼**

| 컬럼 | 설명 |
|---|---|
| # | FIFO 순번 |
| 주문번호 | 연결된 주문 ID |
| 시료ID | 생산 대상 시료 |
| 부족분 / 실생산량 / 총시간 | 생산 수량·시간 정보 |
| 진행률 | `elapsedMinutes / total_time × 100` (WAITING은 0.0%) |
| 상태 | WAITING / IN_PROGRESS |
| 예상완료 | `started_at + total_time` 계산값 (WAITING은 `-`) |

**자동 완료 처리**  
조회 시 IN_PROGRESS 항목의 `elapsedMinutes >= total_time` 확인 →  
완료 조건 충족 시 즉시 처리: `completed=true`, `stock+=actual_qty`, 주문→CONFIRMED

## 4. 새로고침

- Enter 입력 시 데이터 재로드 후 화면 갱신
- `data.json`을 다시 읽어 최신 상태 반영
- **새로고침마다 IN_PROGRESS 생산 완료 여부를 자동 점검**
