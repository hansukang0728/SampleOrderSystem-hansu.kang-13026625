# 모니터링 (Monitoring)

> 참조: [PRD.md](../../PRD.md) — M-01, M-02  
> M-03(생산 큐 현황)은 Phase 4-6 생산 라인에서 표시

---

## 1. 개요

주문 현황(상태별 건수)과 재고 현황(시료별 상태)을 한 화면에 표시하는 대시보드.  
REJECTED 상태는 주문 현황에서 제외한다.  
조회 시마다 `checkAndComplete()`를 실행하여 생산 완료 항목을 자동 갱신한다.

---

## 2. 화면 구성

```
  ╔══════════════════════════════════════════════════════════╗
  ║   모니터링 대시보드                  📅 2026-05-08 15:30:00
  ╚══════════════════════════════════════════════════════════╝

  [ 주문 현황 ]  (REJECTED 제외)          🕐 2026-05-08 15:30:00
  ──────────────────────────────────────────────────────────
   RESERVED    :  2건
   PRODUCING   :  1건
   CONFIRMED   :  3건
   RELEASE     :  5건
  ──────────────────────────────────────────────────────────

  [ 재고 현황 ]                           🕐 2026-05-08 15:30:00
  ──────────────────────────────────────────────────────────
   ID      이름                  재고(ea)   상태
  ──────────────────────────────────────────────────────────
   S-001   알파-시료                100 ea   여유  ●
   S-002   베타-시료                  5 ea   부족  ▲
   S-003   감마-시료                  0 ea   고갈  ✕
  ──────────────────────────────────────────────────────────

  [Enter] 새로고침   [0] 뒤로   [m] 메인
```

**업데이트 시간 표시 규칙**
- 헤더 우측: 대시보드 진입·새로고침 시각
- 각 섹션 우측: 해당 섹션 데이터 조회 시각 (`nowStr()`)
- `collect()` 호출 시점의 시각을 캡처하여 모든 섹션에 동일하게 표시

---

## 3. 섹션별 상세

### 3.1 주문 현황 (M-02)

- RESERVED / PRODUCING / CONFIRMED / RELEASE 상태별 건수 출력
- **REJECTED 제외**
- 상태가 0건이어도 행 표시

### 3.2 재고 현황 (M-01)

재고 상태 기준 (시료별, 주문 수요 대비 계산):

| 상태 | 조건 | 아이콘 | 색상 |
|---|---|---|---|
| 고갈 | `stock == 0` | ✕ | Red |
| 부족 | `stock > 0` AND `(stock + 생산중 입고량) < RESERVED 수요` | ▲ | Yellow |
| 여유 | `stock > 0` AND `(stock + 생산중 입고량) >= RESERVED 수요` | ● | Green |

**계산 정의**
- `생산중 입고량` = 해당 시료의 미완료 생산 큐 `actual_qty` 합계
- `RESERVED 수요` = 해당 시료의 RESERVED 주문 `quantity` 합계
- RESERVED 수요 == 0 이면 항상 여유 (단, stock > 0)

**예시**

| stock | 생산중 | RESERVED 수요 | 상태 |
|---|---|---|---|
| 0 | 57 | 50 | 고갈 |
| 5 | 0 | 3 | 여유 (5 ≥ 3) |
| 5 | 0 | 10 | 부족 (5 < 10) |
| 5 | 57 | 60 | 여유 (62 ≥ 60) |
| 3 | 10 | 20 | 부족 (13 < 20) |

---

## 4. 입력 처리

| 입력 | 동작 |
|---|---|
| Enter | 데이터 재로드 + 화면 갱신 |
| `0` | 메인 메뉴로 복귀 |
| `m` | 메인 메뉴로 즉시 이동 |
