# 생산 라인 (Production Line)

> 참조: [PRD.md](../../PRD.md) — P-01, P-02, P-03, P-04

---

## 1. 개요

단일 생산 라인의 **현재 생산 현황**과 **대기 주문 목록**을 조회한다.  
조회 시마다 IN_PROGRESS 항목의 경과 시간을 확인해 완료 조건 충족 시 자동 처리한다.  
대기 주문 스케줄링 전략: **FIFO(선입선출)**

### 생산 상태 3단계

```
enqueue 시 (자동 시작)         경과 >= total_time
     │                               │
  IN_PROGRESS ──────────────────── DONE ── 다음 WAITING 자동 시작 →
(started_at = 현재시각)         (completed=true,
                                 stock+=actual_qty,
                                 주문→CONFIRMED)

※ WAITING: IN_PROGRESS 항목 존재 시 대기 (FIFO 순서 유지)
```

**FIFO 자동 스케줄링 규칙**
- 큐에 등록(enqueue) 시 IN_PROGRESS·WAITING 항목이 없으면 즉시 시작
- IN_PROGRESS 항목이 완료되면 첫 번째 WAITING 항목 자동 시작
- 수동 시작 버튼 없음 — 전적으로 자동 처리

## 3. 섹션별 상세

### 3.1 생산 현황 (IN_PROGRESS)

현재 생산 중인 항목 상세 정보를 카드 형식으로 출력.  
IN_PROGRESS 항목 없으면: `"현재 생산 중인 작업이 없습니다."` 출력

**표시 항목**

| 항목 | 설명 | 출처 |
|---|---|---|
| 주문번호 | Order ID | Order |
| 시료 | 시료 ID + 이름 | Sample |
| 고객명 | 주문자 | Order |
| 주문 시각 | 주문 접수 시각 | Order.created_at |
| 생산 시작 | IN_PROGRESS 전환 시각 | queue.started_at |
| 부족분 | 생산해야 할 수량 | queue.shortage |
| 실 생산량 | 총 생산 목표 | queue.actual_qty |
| 총 생산시간 | 예정 소요 시간 (분) | queue.total_time |
| **현재 생산량** | `progressPct() × actual_qty / 100` (추정) | 계산값 |
| **예상 완료** | `started_at + total_time` | 계산값 |

### 3.2 대기 주문 (WAITING · FIFO)

`enqueued_at` 오름차순으로 정렬된 WAITING 항목 목록.  
WAITING 항목 없으면: `"대기 중인 주문이 없습니다."` 출력

**표시 항목**: #(순번), 주문번호, 시료, 고객명, 수량, 대기 시작(`enqueued_at`)

### 3.3 생산 시작 [s]

첫 번째 WAITING 항목을 IN_PROGRESS로 전환.

```
WAITING 항목 없음 → "시작 가능한 작업이 없습니다."
WAITING 있음      → started_at = nowStr()
                    WAITING → IN_PROGRESS
                    data.json 저장
                    화면 즉시 갱신
```

## 4. 생산 계산 공식

```
actual_qty  = ceil(shortage / (yield_rate × 0.9))
total_time  = avg_production_time × actual_qty  (분)
현재 생산량 = int(progressPct() × actual_qty / 100)   (추정, 소수점 버림)
예상 완료   = parseTime(started_at) + total_time × 60  (초 단위 변환)
```

## 5. 입력 처리

| 입력 | 동작 |
|---|---|
| Enter | 즉시 새로고침 (자동 완료·자동 시작 점검 포함) |
| `0` | 뒤로 |
| `m` | 메인 메뉴 즉시 이동 |

**자동 새로고침**: 3초 간격으로 화면 자동 갱신
- 현재 시각(`nowStr()`) 갱신
- `checkAndComplete()` 실행 → 완료된 항목 즉시 반영
- IN_PROGRESS 진행률(`progressPct()`) 실시간 업데이트
- 키 입력 대기와 병행하여 논블로킹 방식으로 처리
