# 생산 라인 (Production Line)

> 참조: [PRD.md](../../PRD.md) — P-01, P-02, P-03, P-04

---

## 1. 개요

단일 생산 라인에서 **FIFO(선입선출)** 방식으로 생산 요청을 처리한다.  
생산은 실제 시간이 경과해야 완료되며, 조회 시마다 경과 시간을 확인해 자동으로 재고와 주문 상태를 갱신한다.

### 생산 상태 3단계

```
enqueue 시                processNext() 호출         경과 >= total_time
     │                         │                          │
  WAITING ──────────────── IN_PROGRESS ─────────────── DONE
(started_at 비어있음)    (started_at = 현재시각)    (completed=true,
                                                     stock+=actual_qty,
                                                     주문→CONFIRMED)
```

## 3. 기능 상세

### 3.1 생산 큐 조회 (P-01)

완료되지 않은(`completed == false`) 생산 작업을 enqueued_at 오름차순(FIFO)으로 출력.  
조회 시마다 IN_PROGRESS 항목의 경과 시간을 확인하여 완료 조건이 충족되면 자동 처리한다.

**출력 예시**
```
──────────────────────────────────────────────────────────────────────
  #   주문번호              시료        부족분  실생산량  총시간(분)  진행률   상태
──────────────────────────────────────────────────────────────────────
  1   ORD-20260508-0002   S-002 베타    45ea    57ea      2565.0    38.2%  IN_PROGRESS
  2   ORD-20260508-0005   S-001 알파    20ea    25ea       762.5     0.0%  WAITING
──────────────────────────────────────────────────────────────────────
전체: 2건  (IN_PROGRESS: 1건 / WAITING: 1건)
```

큐가 비어있을 경우: `"생산 대기 중인 작업이 없습니다."` 출력

---

### 3.2 다음 작업 시작 (P-02)

큐의 **첫 번째 WAITING 항목**을 IN_PROGRESS 상태로 전환한다.  
실제 완료는 경과 시간이 `total_time`에 도달할 때 자동으로 처리된다.

**처리 흐름 — Step 1: 생산 시작 (processNext)**

```
WAITING 항목 존재 확인
  → 없으면 "시작 가능한 작업이 없습니다." 출력 후 종료
  → 첫 번째 WAITING 항목 선택
  → started_at = 현재 시각
  → 상태: WAITING → IN_PROGRESS
  → data.json 저장
  → 결과 출력
```

**처리 흐름 — Step 2: 자동 완료 (조회·모니터링 시마다)**

```
IN_PROGRESS 항목 순회
  → elapsedMinutes(started_at) >= total_time ?
      YES → completed = true
            stock += actual_qty
            주문 상태: PRODUCING → CONFIRMED
            data.json 저장
```

**생산 시작 출력 예시**
```
[ 생산 시작 ]
  주문번호    : ORD-20260508-0002
  시료        : S-002 베타-시료
  부족분      : 45 ea
  실 생산량   : 57 ea
  총 생산시간 : 2565.0분
  시작 시각   : 2026-05-08 10:20:00

✔ 생산이 시작되었습니다. 완료까지 약 2565.0분 소요 예정.
```

**자동 완료 시 출력 예시** (다음 조회 시 감지)
```
[ 생산 완료 감지 ]
  주문번호  : ORD-20260508-0002
  재고 변화 : 5 ea → 62 ea  (+57)
  주문 상태 : PRODUCING → CONFIRMED

✔ 생산 완료 처리되었습니다.
```

## 4. 생산 계산 공식

### 실 생산량 (P-03)

```
actual_qty = ceil(shortage / (yield_rate × 0.9))
```

- `shortage`   : 부족 수량 (주문수량 - 현재재고)
- `yield_rate` : 시료 수율 (0.0 ~ 1.0)
- `× 0.9`      : 수율 오차 보정 계수

**계산 예시**
```
부족분: 45ea, 수율: 0.88
actual_qty = ceil(45 / (0.88 × 0.9)) = ceil(56.82) = 57 ea
```

### 총 생산시간 (P-04)

```
total_time = avg_production_time × actual_qty  (단위: 분)
```

**계산 예시**
```
평균생산시간: 45.0분/ea, 실생산량: 57ea
total_time = 45.0 × 57 = 2565.0분
```

---

## 5. 상태 전이

```
ProductionQueueItem:  WAITING ──(processNext)──→ IN_PROGRESS ──(경과>=total)──→ DONE
Order:                PRODUCING ─────────────────────────────────────────────→ CONFIRMED
```

- `DONE` 전환 시: `completed = true`, `stock += actual_qty`
- `completed = true` 항목은 큐 조회에서 제외
