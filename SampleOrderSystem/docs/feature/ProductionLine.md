# 생산 라인 (Production Line)

> 참조: [PRD.md](../../PRD.md) — P-01, P-02, P-03, P-04

---

## 1. 개요

단일 생산 라인에서 **FIFO(선입선출)** 방식으로 생산 요청을 처리한다.  
생산 완료 시 재고가 증가하고, 해당 주문 상태가 PRODUCING → CONFIRMED로 자동 전환된다.

---

## 2. 서브메뉴 구성

```
============================================================
      생산 라인
============================================================
  1. 생산 큐 조회
  2. 다음 작업 처리 (FIFO)
  0. 뒤로
------------------------------------------------------------
선택:
```

## 3. 기능 상세

### 3.1 생산 큐 조회 (P-01)

대기 중인(`completed == false`) 생산 작업을 FIFO 순서로 출력.

**출력 예시**
```
──────────────────────────────────────────────────────────
  #   주문번호              시료         부족분  실생산량  총생산시간(분)  등록일시
──────────────────────────────────────────────────────────
  1   ORD-20260508-0002   S-002 베타     45ea    57ea      2565.0    2026-05-08 10:20:00
  2   ORD-20260508-0005   S-001 알파     20ea    25ea       762.5    2026-05-08 11:00:00
──────────────────────────────────────────────────────────
대기 중: 2건
```

큐가 비어있을 경우: `"대기 중인 생산 작업이 없습니다."` 출력

---

### 3.2 다음 작업 처리 (P-02)

큐의 **첫 번째(가장 오래된) 항목**을 처리한다.

**처리 흐름**

```
큐 비어있는지 확인
  → 비어있으면 오류 메시지 출력 후 종료
  → 첫 번째 항목 로드
  → 생산 결과 계산 (P-03, P-04)
  → stock += actual_qty
  → completed = true
  → 연결된 주문 상태: PRODUCING → CONFIRMED
  → data.json 저장
  → 결과 출력
```

**처리 결과 출력 예시**
```
[ 생산 처리 ]
  주문번호  : ORD-20260508-0002
  시료      : S-002 베타-시료
  부족분    : 45 ea
  실 생산량 : 57 ea   ← ceil(45 / (0.88 × 0.9))
  총생산시간: 2565.0분 ← 45.0분 × 57ea

[ 처리 결과 ]
  재고 변화 : 5 ea → 62 ea  (+57)
  주문 상태 : PRODUCING → CONFIRMED

✔ 생산 처리 완료.
```

## 4. 생산 계산 공식

### 실 생산량 (P-03)

```
actual_qty = ceil(shortage / (yield_rate × 0.9))
```

- `shortage` : 부족 수량 (주문수량 - 현재재고)
- `yield_rate` : 시료 수율 (0.0 ~ 1.0)
- `× 0.9` : 수율 오차 보정 계수

**계산 예시**
```
부족분: 45ea, 수율: 0.88
actual_qty = ceil(45 / (0.88 × 0.9))
           = ceil(45 / 0.792)
           = ceil(56.82)
           = 57 ea
```

### 총 생산시간 (P-04)

```
total_time = avg_production_time × actual_qty  (단위: 분)
```

**계산 예시**
```
평균생산시간: 45.0분/ea, 실생산량: 57ea
total_time = 45.0 × 57 = 2565.0분
```

---

## 5. 상태 전이

```
PRODUCING ──(생산 완료)──→ CONFIRMED
```

- 생산 완료 후 주문의 `status`를 CONFIRMED로 변경
- 재고(`stock`)에 `actual_qty` 만큼 추가
- `ProductionQueueItem.completed = true`
