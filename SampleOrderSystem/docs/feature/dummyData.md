# 더미 데이터 / 초기화 (Dummy Data)

> 참조: [PRD.md](../../PRD.md) — D-01, D-02, D-03

---

## 1. 개요

개발·테스트를 위한 기초 시료 및 주문 데이터를 자동 생성하거나 전체 데이터를 초기화한다.

---

## 2. 서브메뉴 구성

```
============================================================
      더미 데이터 / 초기화
============================================================
  1. 시료 더미 생성      (D-01, 필수)
  2. 주문 더미 생성      (D-02, 선택)
  3. 전체 데이터 초기화  (D-03, 선택)
  0. 뒤로
------------------------------------------------------------
선택:
```

---

## 3. 기능 상세

### 3.1 시료 더미 생성 (D-01) — 필수

난수 기반으로 시료 N개를 자동 생성하여 data.json에 저장한다.  
기존 시료 데이터에 **추가**된다 (덮어쓰지 않음).

**입력값**

| 항목 | 기본값 | 범위 |
|---|---|---|
| 생성 개수 | 10 | 1 ~ 100 |

**생성 규칙**

| 필드 | 생성 방식 |
|---|---|
| id | 기존 최댓값 + 순번 (`S-NNN`) |
| name | 그리스 문자 풀(20종) + `-시료` 접미사 (21개 이상이면 번호 추가) |
| avg_production_time | 균등분포 10.0 ~ 120.0 분 (소수점 1자리) |
| yield_rate | 균등분포 0.700 ~ 0.990 (소수점 3자리) |
| stock | 균등분포 0 ~ 200 ea |

**출력 예시**
```
생성할 시료 수 (기본 10): 5

  S-001   알파-시료     30.5분   95.0%   재고: 100ea
  S-002   베타-시료     45.0분   88.0%   재고:  50ea
  S-003   감마-시료     60.0분   90.0%   재고:   0ea
  S-004   델타-시료     22.5분   82.5%   재고: 150ea
  S-005   엡실론-시료   75.0분   77.0%   재고:  10ea

✔ 5개 시료가 생성되었습니다.
```

---

### 3.2 주문 더미 생성 (D-02) — 선택

등록된 시료를 기반으로 임의 주문 M건을 자동 생성한다.  
생성된 주문은 모두 RESERVED 상태로 저장된다.

**전제 조건**: 등록된 시료가 1개 이상 있어야 함

**입력값**

| 항목 | 기본값 | 범위 |
|---|---|---|
| 생성 개수 | 5 | 1 ~ 50 |

**생성 규칙**

| 필드 | 생성 방식 |
|---|---|
| id | `ORD-YYYYMMDD-XXXX` 당일 순번 자동 부여 |
| sample_id | 등록된 시료 중 무작위 선택 |
| quantity | 균등분포 1 ~ 50 ea |
| customer_name | 고객명 풀에서 무작위 선택 |
| status | RESERVED |
| created_at | 현재 시각 |

---

### 3.3 전체 데이터 초기화 (D-03) — 선택

data.json의 모든 데이터(시료, 주문, 생산 큐)를 삭제하고 초기 상태로 리셋한다.

**⚠️ 주의**: 이 작업은 되돌릴 수 없습니다.

**확인 절차**
```
⚠️  전체 데이터를 삭제합니다. 이 작업은 되돌릴 수 없습니다.
계속하려면 'YES' 를 입력하세요: YES

✔ 전체 데이터가 초기화되었습니다.
```

`YES` 이외의 입력: `"취소되었습니다."` 출력 후 메뉴로 복귀

---

## 4. 데이터 저장

- 생성·초기화 즉시 data.json write-through 저장
- 더미 생성 시 기존 데이터에 추가 (병합)
- 초기화 시 data.json을 빈 상태로 덮어씀
