# 주문 승인 / 거절 (Order Manager)

> 참조: [PRD.md](../../PRD.md) — O-02, O-02a, O-02b, O-03

---

## 1. 개요

접수된 주문(RESERVED) 목록을 확인하고,  
특정 주문에 대해 **승인** 또는 **거절**을 처리한다.

---

## 2. 서브메뉴 구성

```
============================================================
      주문 승인 / 거절
============================================================
  1. 접수된 주문 목록 조회
  2. 주문 승인
  3. 주문 거절
  0. 뒤로
------------------------------------------------------------
선택:
```

---

## 3. 기능 상세

### 3.1 접수된 주문 목록 조회 (O-02)

RESERVED 상태의 주문만 필터링하여 출력.

**출력 예시**
```
──────────────────────────────────────────────────────────
  주문번호              시료ID   고객명    수량    접수일시
──────────────────────────────────────────────────────────
  ORD-20260508-0001   S-001   홍길동    30 ea  2026-05-08 10:00:00
  ORD-20260508-0002   S-002   김철수    50 ea  2026-05-08 10:15:00
──────────────────────────────────────────────────────────
총 2건 (RESERVED)
```

접수된 주문 없을 경우: `"처리 대기 중인 주문이 없습니다."` 출력

---

### 3.2 주문 승인 (O-02a / O-02b)

**입력값**: 승인할 주문번호

**처리 흐름**

```
주문번호 입력
  → RESERVED 상태 확인
  → 해당 시료의 현재 재고 확인
      │
      ├─ [Case 1] 재고 >= 주문수량
      │     → stock -= quantity
      │     → 주문 상태: CONFIRMED
      │     → "즉시 출고 대기 상태로 전환되었습니다." 출력
      │
      └─ [Case 2] 재고 < 주문수량
            → 부족분 = quantity - stock
            → 실생산량 = ceil(부족분 / (수율 × 0.9))
            → 총생산시간 = 평균생산시간 × 실생산량
            → 생산 큐에 등록 (enqueued_at 기록)
            → 주문 상태: PRODUCING
            → "생산 라인에 등록되었습니다." 출력
```

**Case 1 출력 예시 (재고 충분)**
```
주문번호: ORD-20260508-0001
  → 시료: S-001 알파-시료 | 재고: 100ea | 주문수량: 30ea
  → 재고 충분 → 즉시 CONFIRMED 처리

  재고 차감: 100 → 70 ea
  주문 상태: CONFIRMED
✔ 승인 완료. 출고 대기 중입니다.
```

**Case 2 출력 예시 (재고 부족)**
```
주문번호: ORD-20260508-0002
  → 시료: S-002 베타-시료 | 재고: 5ea | 주문수량: 50ea
  → 재고 부족 (부족분: 45ea) → 생산 라인 등록

  실 생산량  : ceil(45 / (0.88 × 0.9)) = 57 ea
  총 생산시간: 45.0분 × 57 = 2565.0분
  주문 상태  : PRODUCING
✔ 승인 완료. 생산 라인에 등록되었습니다.
```

---

### 3.3 주문 거절 (O-03)

**입력값**: 거절할 주문번호

**처리 흐름**
```
주문번호 입력
  → RESERVED 상태 확인
  → 주문 상태: REJECTED
  → data.json 저장
  → "주문이 거절되었습니다." 출력
```

**출력 예시**
```
주문번호: ORD-20260508-0001
  → 고객: 홍길동 | 시료: S-001 | 수량: 30ea
거절 사유 (선택입력, Enter 생략가능):

주문 상태: REJECTED
✔ 거절 처리 완료.
```

---

## 4. 유효성 검증

| 항목 | 검증 조건 | 오류 메시지 |
|---|---|---|
| 주문번호 | 존재하는 주문 | `"존재하지 않는 주문번호입니다."` |
| 주문 상태 | RESERVED 상태여야 함 | `"RESERVED 상태의 주문만 처리 가능합니다."` |

---

## 5. 상태 전이 요약

```
RESERVED ──(승인, 재고 충분)──→ CONFIRMED
         ──(승인, 재고 부족)──→ PRODUCING
         ──(거절)           ──→ REJECTED
```
