# 출고 처리 (Release)

> 참조: [PRD.md](../../PRD.md) — O-04

---

## 1. 개요

재고가 확보된 주문(CONFIRMED)을 선택하여 최종 출고 처리한다.  
출고 완료 후 주문 상태는 **RELEASE**로 변경되며, 이는 최종 상태다.

---

## 2. 처리 흐름

```
메인 메뉴 → [6] 출고 처리
  → CONFIRMED 상태 주문 목록 출력
  → 주문번호 입력
  → 상태 확인 (CONFIRMED 여부)
  → 주문 상태: CONFIRMED → RELEASE
  → data.json 저장
  → 결과 출력
```

---

## 3. UI 흐름 예시

**CONFIRMED 주문 목록 출력**
```

  주문번호              시료ID   고객명    수량    확정일시

출고할 주문번호 (0: 취소):
```

**출고 처리 결과 출력**
```
주문번호: ORD-20260508-0001
  시료  : S-001 알파-시료
  고객  : 홍길동
  수량  : 30 ea

주문 상태: CONFIRMED → RELEASE
✔ 출고 처리 완료.
```

---

## 4. 유효성 검증

| 항목 | 검증 조건 | 오류 메시지 |
|---|---|---|
| 주문번호 | 존재하는 주문 | `"존재하지 않는 주문번호입니다."` |
| 주문 상태 | CONFIRMED 상태여야 함 | `"CONFIRMED 상태의 주문만 출고 가능합니다."` |

---

## 5. 상태 전이

```
CONFIRMED ──(출고)──→ RELEASE
```

- RELEASE는 최종 상태로, 이후 상태 변경 불가
- 재고 변화 **없음** (재고 차감은 승인 시 처리됨)

---

## 6. 출고 가능 주문 없을 경우

```
[ 출고 가능 주문 목록 (CONFIRMED) ]
현재 출고 대기 중인 주문이 없습니다.
```
