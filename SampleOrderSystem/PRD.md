# SampleOrderSystem — Product Requirements Document (PRD)

## 1. 제품 개요

시료의 등록부터 주문, 생산, 출고까지 전체 라이프사이클을 관리하는 콘솔 기반 시료 주문 시스템.

---

## 2. 기능 요구사항

### ① 시료 관리 (Sample Management)

| ID | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| S-01 | 시료 등록 | 이름·평균생산시간·수율·초기재고 입력 → ID(`S-NNN`) 자동 부여 | 필수 |
| S-02 | 전체 조회 | 등록된 모든 시료 목록 출력 (재고 상태 포함) | 필수 |
| S-03 | ID 조회 | `S-NNN` 입력 → 해당 시료 상세 정보 출력 | 필수 |
| S-04 | 이름 검색 | 키워드 입력 → 이름에 포함된 시료 목록 출력 | 필수 |
| S-05 | ~~재고 상태 표시~~ | ~~여유(≥11) / 부족(1~10) / 고갈(0) 구분 표기~~ | **모니터링(M-01)으로 이관** |

### ② 주문 관리 (Order Management)

| ID | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| O-01 | 주문 생성 | sample_id + 수량 + 고객명 입력 → `ORD-YYYYMMDD-XXXX` 자동 부여, RESERVED 상태 | 필수 |
| O-02 | 주문 승인 | RESERVED 주문 선택 → 재고 상황에 따라 자동 분기 처리 | 필수 |
| O-02a | └ 재고 충분 | stock ≥ quantity → stock 차감, 상태: CONFIRMED | 필수 |
| O-02b | └ 재고 부족 | stock < quantity → 부족분 생산 큐 등록, 상태: PRODUCING | 필수 |
| O-03 | 주문 거절 | RESERVED 주문 선택 → 상태: REJECTED | 필수 |
| O-04 | 주문 출고 | CONFIRMED 주문 선택 → 상태: RELEASE | 필수 |
| O-05 | 주문 목록 조회 | 전체 주문 목록 출력 (REJECTED 제외 필터 옵션) | 필수 |

### ③ 생산 라인 (Production Line)

| ID | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| P-01 | 생산 큐 조회 | 대기 중인 생산 작업 목록 출력 (FIFO 순서) | 필수 |
| P-02 | 다음 작업 처리 | 큐 앞단 1건 처리 → stock 증가, 주문 상태 PRODUCING → CONFIRMED | 필수 |
| P-03 | 생산량 계산 | 실생산량 = `ceil(부족분 / (수율 × 0.9))` | 필수 |
| P-04 | 생산시간 계산 | 총생산시간 = `평균생산시간 × 실생산량` | 필수 |

### ④ 모니터링 (Monitoring)

| ID | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| M-01 | 재고 현황 대시보드 | 전체 시료의 재고 수량 및 상태(여유/부족/고갈) 일괄 표시 | 필수 |
| M-02 | 활성 주문 현황 | REJECTED 제외한 주문 목록 및 상태 표시 | 필수 |
| M-03 | 생산 큐 현황 | 대기 중인 생산 작업 수 및 목록 표시 | 필수 |

### ⑤ 더미 데이터 생성 (Dummy Data)

| ID | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| D-01 | 시료 더미 생성 | 난수 기반 시료 N개 자동 생성 및 저장 | 필수 |
| D-02 | 주문 더미 생성 | 등록된 시료 기반 임의 주문 M건 자동 생성 | 선택 |
| D-03 | 데이터 초기화 | 전체 데이터 삭제 후 초기 상태로 리셋 | 선택 |

---

## 3. 완료 기준 (Definition of Done)

- [ ] 시료 CRUD 및 재고 상태 표시 정상 동작
- [ ] 주문 생성 → 승인(재고 충분/부족 분기) → 거절 정상 동작
- [ ] 생산 큐 FIFO 처리 및 재고·주문 상태 자동 갱신 정상 동작
- [ ] 출고(RELEASE) 처리 정상 동작
- [ ] 프로그램 재실행 후 데이터 유지 (JSON 영속성)
- [ ] 더미 데이터 생성 기능 동작
- [ ] 콘솔 한글 출력 정상 (UTF-8)

---

## 4. 범위 외 (Out of Scope)

- GUI / Web UI
- 네트워크 통신, 멀티 사용자 동시 접근
- 외부 DB (SQLite, MySQL 등)
- 다중 생산 라인
